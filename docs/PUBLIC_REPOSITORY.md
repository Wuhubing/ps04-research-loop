# Public repository scope

The student authorized public code and retained evidence. Normalized source records, versioned text/transcripts, prompts, responses, decisions, receipts and editorial review are included. Private voice samples, downloaded audio/video, environments, authentication files and bulky raw extractor discovery JSON are excluded. Discovery JSON can contain temporary media delivery signatures; it remains locally preserved rather than being published. Normalized candidates retain original URLs and provenance. Media is recoverable from candidates using the extraction component.

Pattern checks found no API credentials in included project text. Apparent sk- matches in URLs were article slugs or media signatures, not API keys. Public source content remains attributed to its original authors.
